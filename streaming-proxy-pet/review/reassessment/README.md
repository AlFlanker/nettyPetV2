# Независимые повторные ревью

Сохранены выводы четырёх экспертов о версии с прямым io.netty:

* [Jetty / Servlet](jetty.md)
* [Netty](netty.md)
* [Spring](spring.md)
* [Технический лид](tech-lead.md)

Это исходные отчёты на момент независимого чтения кода. Они сохраняют выводы на момент независимой проверки и, где уже подготовлены,
дополнения эксперта после исправления. Часть отчётов ещё описывает обнаруженный
затем исправленный AsyncContext blocker и предыдущий результат тестов.

Актуальные статусы исправлений и итоговая проверка находятся в
[общей оценке](../ASSESSMENT.md). Число тестов и состояние исходников в старых
отчётах не следует принимать за состояние после исправлений.

Итоговая общая проверка завершена: **41 тест прошёл**, `test installDist`
успешен, все контексты завершились без graceful-shutdown timeout. В начале каждого
отчёта добавлен статус после валидации; исходные находки ниже него сохранены как
история причин исправлений.
